## 🔤 Alphabetical Index

### A

#### Air-Gapping
* **Plain-English Definition:** A physical security measure where a computer, server, or database is physically disconnected from all local networks, corporate intranets, and the public internet.
* **Why it's used in Project Red Sky:** Used in [[04_Financial_Protection_and_Fintech_Trust#The Clean Wall|The Clean Wall]] in NTL's Jashore Data Center to isolate mandatory 24-month Call Detail Records (CDRs) from commercial marketing databases.

#### Apache Atlas
* **Plain-English Definition:** A powerful, open-source metadata management and data governance framework designed for large enterprise data systems.
* **Why it's used in Project Red Sky:** Automatically tracks data lineage across NTL’s Hadoop and Spark lakehouses, ensuring IT always knows where every customer’s personal records are stored. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense]].

#### Apache Iceberg
* **Plain-English Definition:** An open, high-performance table format for massive analytic datasets that allows multiple computing engines (Spark, Trino, Flink) to safely query the same data without corrupting it.
* **Why it's used in Project Red Sky:** Works alongside Apache Atlas to provide point-in-time time-travel audits and clean data pruning for customer erasure requests.

#### ARIA (Automated Risk Identification & Auditing)
* **Plain-English Definition:** An automated software compliance scanner embedded directly into software deployment pipelines.
* **Why it's used in Project Red Sky:** Prevents unconsented, biased, or data-leaking machine learning models from being deployed into production without explicit approval. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Backup Slide 32]].

#### ARPU (Average Revenue Per User)
* **Plain-English Definition:** A core telecom financial metric representing the average revenue generated by a single active customer each month:
  $$\text{ARPU} = \frac{\text{Total Monthly Revenue}}{\text{Total Active Subscribers}}$$
* **Context:** In Bangladesh, an average rural user has an ARPU of ~BDT 150/month, whereas NTL's top 1.2M elite post-paid and enterprise subscribers have an ARPU of **BDT 800+/month**. See [[01_The_Human_Crisis_and_Field_Evidence#Tanvir]].

### B

#### Bdapps
* **Plain-English Definition:** The premier third-party developer ecosystem and carrier-billing app store in Bangladesh, originally founded by Robi Axiata.
* **Context:** Rogue developers historically exploited carrier billing on platforms like Bdapps to create unauthorized subscription traps. Project Red Sky sandboxes these developers and enforces a 14-day escrow buffer. See [[04_Financial_Protection_and_Fintech_Trust#Airtime Vault]].

#### Blind Flexiload (The No-Khata Mandate)
* **Plain-English Definition:** A network-level airtime recharge protocol where the customer generates a dynamic 6-digit one-time token via USSD (`*1218*2#`) instead of speaking or writing their 11-digit mobile number at retail stalls. See [[03_Consumer_and_Retail_Privacy_Shield#Backup Slide 23]].

#### BSS (Business Support System)
* **Plain-English Definition:** The core telecommunications enterprise software that manages customer billing, product orders, customer relationship management (CRM), and subscription lifecycles.

#### BTRC (Bangladesh Telecommunication Regulatory Commission)
* **Plain-English Definition:** The statutory government regulatory agency responsible for regulating telecommunications networks, frequency spectrum, and operating licenses in Bangladesh.
* **Statutory Duty:** Under **Section 97 of the Bangladesh Telecommunication Act 2001**, BTRC mandates that operators retain customer call records for **24 months**. See [[04_Financial_Protection_and_Fintech_Trust#The Clean Wall]].

#### Button Phone / Feature Phone
* **Plain-English Definition:** A low-cost cellular handset with physical mechanical keypad buttons, a non-touch screen, and no modern smartphone operating system (Android/iOS).
* **Scale in Bangladesh:** Over **35% of NTL's subscribers (~20 Million+ people)** rely exclusively on button phones. See [[01_The_Human_Crisis_and_Field_Evidence#Kashem Bhai]].

---

### C

#### CAMARA Project (GSMA)
* **Plain-English Definition:** An international open-source project led by the GSMA and Linux Foundation to standardize universal programmable telecom APIs across global mobile operators.
* **Why it's used in Project Red Sky:** Used to expose the **Bank SIM-Swap Check API** to commercial banks, generating +BDT 11.4 Cr/year in new revenue. See [[04_Financial_Protection_and_Fintech_Trust#Backup Slide 28]].

#### CapEx (Capital Expenditure)
* **Plain-English Definition:** Money spent by a company to purchase, build, or upgrade physical assets or long-term infrastructure (servers, software licenses, network nodes).
* **NTL Investment:** Project Red Sky requires **BDT 29.6 Crore CapEx**, phased over two years with a ~22-month payback. See [[07_Financial_Engine_ROI_and_Execution_Roadmap]].

#### CDO (Chief Data Officer) / DPO (Data Protection Officer)
* **Plain-English Definition:** A senior corporate executive mandated under **PDPA 2026 Section 23** who reports directly to the Board Audit Committee and has independent statutory veto power over unsafe digital products. See [[06_Enterprise_Governance_and_Board_Accountability#Backup Slide 35]].

#### CDR (Call Detail Record)
* **Plain-English Definition:** A digital ledger entry produced by telephone exchanges containing metadata about a call: caller number, recipient number, timestamp, call duration, and cellular tower ID. Does **not** contain voice audio recordings.

#### CI/CD Pipeline (Continuous Integration / Continuous Deployment)
* **Plain-English Definition:** An automated engineering workflow where software code is automatically built, tested for bugs and security flaws, and deployed to live servers. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Backup Slide 32]].

#### Crypto-Shredding / Key Destruction
* **Plain-English Definition:** A data erasure method where instead of physically finding and deleting every historical backup tape across multiple data centers, the specific mathematical encryption key used to encrypt that customer's files is permanently destroyed.
* **Result:** Makes the historical backup files permanently unreadable and impossible to decrypt, legally satisfying the Right to Erasure under PDPA Section 13(2). See [[04_Financial_Protection_and_Fintech_Trust#The Clean Wall]].

### D

#### Dark Lakehouses
* **Plain-English Definition:** Massive enterprise data lakes (Hadoop/Spark clusters) containing unmapped, unclassified, and forgotten customer datasets with zero data lineage tracking. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Deep-Dive: Shedding Light on Dark Lakehouses]].

#### Differential Privacy
* **Plain-English Definition:** A mathematical technique that injects precisely calibrated statistical noise into a machine learning training dataset.
* **Why it's used in Project Red Sky:** Allows AI models to learn broad customer behavior patterns without memorizing any individual customer's specific personal records, defeating Model Inversion attacks. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Threat 2: Model Inversion]].

#### DLP (Data Loss Prevention)
* **Plain-English Definition:** A cybersecurity system that monitors, detects, and blocks sensitive information (such as National IDs or credit card numbers) from being copied, emailed, or exported outside the company's approved network boundary.

---

### E

#### eBPF / XDP (Extended Berkeley Packet Filter)
* **Plain-English Definition:** A revolutionary Linux kernel technology that allows high-performance security programs to run directly inside the operating system core without slowing down network speeds.
* **Why it's used in Project Red Sky:** Inspects outbound server traffic at line speed to physically drop unapproved overseas data transfers (satisfying PDPA Section 29).

#### EBITDA (Earnings Before Interest, Taxes, Depreciation, and Amortization)
* **Plain-English Definition:** The gold-standard measure of a company's core operating profitability.
* **NTL Projection:** Project Red Sky delivers **+BDT 35.5 Crore in net accretive EBITDA per year** by Year 3. See [[07_Financial_Engine_ROI_and_Execution_Roadmap]].

#### e-KYC (electronic Know Your Customer)
* **Plain-English Definition:** The digital process used to verify a customer’s identity remotely using their National ID (NID) card and facial biometrics during SIM card purchase. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Threat 1: The Deepfake e-KYC Attack]].

#### Ephemeral / Volatile Memory (RAM)
* **Plain-English Definition:** Computer storage that only holds data while active operations are running and completely erases everything the instant power is cut or the task finishes, leaving zero traces on hard disks.

#### Escrow Buffer
* **Plain-English Definition:** A financial safeguard where revenue earned by third-party software developers is held in trust by NTL for **14 days** before disbursement. If a customer reports an unauthorized charge, the money is immediately refunded from the escrow. See [[04_Financial_Protection_and_Fintech_Trust#Deep-Dive: The Airtime Vault]].

#### FTE (Full-Time Equivalent)

### G

#### Guardian Child-Shield (`*1218*4#`)
* **Plain-English Definition:** A network-level toggle that allows parents to dial `*1218*4#` on any family handset to instantly block ad tracking beacons, third-party VAS charges, and commercial behavioral profiling.
* **Statutory Alignment:** Fulfills **PDPA 2026 Section 9 & Definition 2(13)**. See [[03_Consumer_and_Retail_Privacy_Shield#Main Deck Slide 05 & Backup Slide 25]].

### I

#### IMS (IP Multimedia Subsystem)
* **Plain-English Definition:** The core telecommunications architecture that routes high-speed IP voice calls (VoLTE), multimedia sessions, and signaling across cellular networks.
* **Why it's used in Project Red Sky:** Acts as the virtual proxy engine that bridges delivery couriers with customers during **Stealth Number** calls without exposing real phone numbers. See [[03_Consumer_and_Retail_Privacy_Shield#Backup Slide 22]].

### K

#### Khata (খাতা)
* **Plain-English Definition:** A traditional, physical paper notebook used by over 250,000 grocery store owners (*mudir dokan*) across Bangladesh to write down customer phone numbers during airtime recharges.
* **The Vulnerability:** Examined in academic studies (Haque et al., ACM ICTD 2020) as the primary physical leak exposing numbers to female harassment and commercial spam brokers. Solved by **Blind Flexiload**. See [[01_The_Human_Crisis_and_Field_Evidence#Kashem Bhai]].

---

### M

#### Masked Agent Desk
* **Plain-English Definition:** A call-center software interface where customer service agents see partially hidden numbers (`018-XXXX-1234`). Full numbers can only be unmasked if the customer provides a live SMS one-time password. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Main Deck Slide 07]].

#### Model Inversion (OWASP LLM06)
* **Plain-English Definition:** An adversarial machine learning attack where a hacker queries an AI model repeatedly to mathematically reconstruct and extract the confidential training data it was trained on. Defeated by **Differential Privacy**. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Threat 2: Model Inversion]].

#### MSISDN (Mobile Station International Subscriber Directory Number)
* **Plain-English Definition:** The international technical term for a mobile phone number (e.g., `+880 1819-452783`). In Bangladesh, it functions as a citizen's master digital key. See [[01_The_Human_Crisis_and_Field_Evidence#Fatema]].

---

### N

#### NID (National Identification Number)
* **Plain-English Definition:** The unique 10- or 17-digit citizen identity number issued by the Bangladesh Election Commission, legally required for all biometric SIM card registrations.

#### NID Watch (`*1218*5#`)
* **Plain-English Definition:** An automated consumer security alert that sends an instant SMS notification whenever a new SIM card is registered using the customer's National ID, allowing one-key freezing of fraudulent lines. See [[04_Financial_Protection_and_Fintech_Trust#Main Deck Slide 06]].

---

### O

#### OCS (Online Charging System)
* **Plain-English Definition:** The real-time telecommunications billing engine that calculates balances, deducts call charges, and credits airtime in milliseconds.
* **Role in Blind Flexiload:** Translates dynamic 6-digit tokens into account credits entirely in working memory without logging phone numbers. See [[03_Consumer_and_Retail_Privacy_Shield#Backup Slide 23]].

#### OpenLineage
* **Plain-English Definition:** An open-source industry standard for tracking metadata and operational data lineage across complex big data processing platforms (Spark, Airflow, Flink).

#### OpEx (Operating Expenditure)
* **Plain-English Definition:** The ongoing, recurring cash required to run daily business operations (employee salaries, cloud hosting fees, electricity, customer care). Project Red Sky models **-BDT 20.2 Cr/year in core OpEx**. See [[07_Financial_Engine_ROI_and_Execution_Roadmap]].

#### OWASP Top 10 for Large Language Models
* **Plain-English Definition:** The authoritative international cybersecurity standard listing the ten most critical vulnerabilities affecting generative AI systems (including Prompt Injection LLM01 and Model Inversion LLM06).

### P

#### PDPA 2026 (Personal Data Protection Act 2026, Act No. 63 of 2026)
* **Plain-English Definition:** Bangladesh's landmark national data privacy statute establishing mandatory legal rights for citizens (consent, access, correction, erasure) and severe financial penalties for non-compliant corporations.
* **Key Sections:**
  * **Section 9 & Def 2(13):** Guardian consent required for processing children's data (<18).
  * **Section 13(2):** Mandatory Right to Erasure within 24 hours.
  * **Section 15:** Right to explainability for automated algorithmic decisions.
  * **Section 16:** Statutory duty of data confidentiality.
  * **Section 23:** Mandatory appointment of an independent Chief Data Officer.
  * **Section 29–30:** Strict restrictions on cross-border data transfers.

#### PII (Personally Identifiable Information)
* **Plain-English Definition:** Any data element (name, phone number, biometric, National ID, address) that can be used alone or combined to identify a specific human being.

#### POS Terminal (Point of Sale)
* **Plain-English Definition:** The electronic handheld device or smartphone used by roadside recharge shopkeepers to enter customer airtime credits.

#### Prompt Injection (OWASP LLM01)
* **Plain-English Definition:** A cyberattack where an attacker embeds malicious instructions inside an AI query to trick the model into bypassing safety filters or revealing restricted data. Defeated by the **Sovereign AI Gateway**. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Sovereign AI Gateway]].

### R

#### Recycled SIM Quarantine
* **Plain-English Definition:** An automated telecom lifecycle pipeline that holds dormant numbers in isolation for 90 days after BTRC's 12-month cancellation cutoff and pushes automated webhooks to commercial banks to unlink old bank accounts before the SIM is reissued. See [[03_Consumer_and_Retail_Privacy_Shield#Backup Slide 24]].

### S

#### Shadow AI
* **Plain-English Definition:** The unsanctioned, unmonitored use of third-party public AI applications (like free ChatGPT) by corporate employees to analyze confidential business data. Blocked by NTL’s **Sanitized Enterprise AI Portal**. See [[06_Enterprise_Governance_and_Board_Accountability#Backup Slide 34]].

#### Sovereign AI Gateway
* **Plain-English Definition:** An on-premises microservice proxy hosted on NTL’s private cloud that intercepts outbound AI prompts, scrubs all personal identifiers (names, phone numbers, NIDs) in volatile RAM in under 30 milliseconds, and injects synthetic tokens before querying external cloud LLMs. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Backup Slide 30]].

#### Split-ZK (Zero-Knowledge Proof)
* **Plain-English Definition:** A cryptographic protocol that mathematically verifies a factual claim (e.g., *"Is this customer over 18 years old?"*) without revealing any underlying personal information (such as their birthdate, name, or National ID). See [[03_Consumer_and_Retail_Privacy_Shield#Age Proof Without ID]].

#### Stage-Gate Capital Release
* **Plain-English Definition:** A corporate project management framework where financial capital is divided into phases, and money for the subsequent phase is released by the board **only after the previous phase successfully hits its verified operational KPIs**. See [[07_Financial_Engine_ROI_and_Execution_Roadmap#Backup Slide 36]].

#### Stealth Number (ছদ্মবেশী মোড)
* **Plain-English Definition:** A disposable, 24-hour virtual mobile number proxy generated by the IMS core switch for e-commerce deliveries, masking both the customer’s and rider’s real numbers during calls. See [[03_Consumer_and_Retail_Privacy_Shield#Backup Slide 22]].

#### Sunk Infrastructure / Sunk Cloud
* **Plain-English Definition:** Existing corporate hardware and enterprise cloud software that has already been purchased, deployed, and paid for in previous budget cycles.
* **Impact:** Reusing NTL’s sunk VMware Cloud Foundation private cloud avoids **over BDT 65 Crore** in unnecessary new server purchases. See [[02_Network_Architecture_and_The_Core_Moat#Slide 03]].

---

### T

#### Telecom Act 2001 (Section 97)
* **Plain-English Definition:** The primary telecommunications law of Bangladesh. Section 97 mandates that cellular operators retain call detail records and tower telemetry for **24 months** for national security and lawful interception. See [[04_Financial_Protection_and_Fintech_Trust#The Clean Wall]].

#### The Clean Wall
* **Plain-English Definition:** Project Red Sky's dual-tier database architecture that resolves the statutory clash between PDPA 2026 (erasing marketing profiles in 24 hours) and the Telecom Act 2001 (retaining call logs for 24 months in an isolated, air-gapped WORM vault in Jashore). See [[04_Financial_Protection_and_Fintech_Trust#The Clean Wall]].

#### The Never List
* **Plain-English Definition:** Five non-negotiable consumer privacy covenants enacted directly into NTL’s Board of Directors Charter (Never Sell Location Data, Never Permit Silent Charges, Never Profile Children, Never Export Data Overseas, Never Profit from Breaches). See [[06_Enterprise_Governance_and_Board_Accountability#Backup Slide 37]].

#### TreeSHAP / SHAP (SHapley Additive exPlanations)
* **Plain-English Definition:** A game-theoretic mathematical algorithm used in machine learning to explain which specific factors caused an AI model to make a prediction (e.g., why a customer was flagged for churn or approved for credit). Powers NTL’s **Plain-Bangla SMS Explanation Cards**. See [[05_Sovereign_AI_Data_Lineage_and_Cyber_Defense#Backup Slide 32]].

#### Two-Way Number Masking
* **Plain-English Definition:** A telecom bridging technique where neither the caller nor the recipient can view each other’s genuine phone number in their respective call logs. Used in **Stealth Number**. See [[03_Consumer_and_Retail_Privacy_Shield#Backup Slide 22]].

### U

#### USSD (Unstructured Supplementary Service Data)
* **Plain-English Definition:** The universal GSM cellular signaling protocol initiated by dialing `*` and ending with `#` (e.g., `*1218#`). Works without an internet connection on 100% of mobile phones. See [[01_The_Human_Crisis_and_Field_Evidence#Backup Slide 20]].

---

### V

#### VAS (Value Added Services)
* **Plain-English Definition:** Non-core cellular digital services (caller tunes, horoscope texts, cricket alerts, gaming portals) billed directly against a customer's airtime balance. Historically prone to predatory billing traps; secured by the **Airtime Vault**. See [[01_The_Human_Crisis_and_Field_Evidence#Tanvir]].

#### VCF (VMware Cloud Foundation)
* **Plain-English Definition:** NTL’s existing on-premises enterprise private cloud platform that provides virtualized compute, storage, and networking on company-owned servers.

### W

#### WAP Billing & Header Enrichment
* *See:* **[[#WAP Billing & Header Enrichment]]** in [[04_Financial_Protection_and_Fintech_Trust#Deep-Dive: The Airtime Vault]].

#### WASI / WebAssembly Sandbox
* **Plain-English Definition:** A lightweight, secure software execution environment that isolates third-party code from the underlying operating system and network, ensuring partner developers cannot access unauthorized memory or raw customer phone numbers.

#### WORM Storage (Write Once, Read Many)
* **Plain-English Definition:** A physical digital storage system where recorded data can never be edited, overwritten, or deleted. Used in the Jashore compliance vault to preserve tamper-proof Call Detail Records under legal hold. See [[04_Financial_Protection_and_Fintech_Trust#The Clean Wall]].

### Z

#### Zero-Trust Architecture
* **Plain-English Definition:** A cybersecurity framework based on the principle *"Never Trust, Always Verify"*, requiring continuous cryptographic verification for every user, device, and API query attempting to access customer personal data. See [[02_Network_Architecture_and_The_Core_Moat#Slide 03]].
